Miro Campaign Flow Generator

Build your campaign steps, click Generate — the flow appears on your Miro board.

⚠️ One quick setup step needed

Browsers block API calls from local files. You need a local server. Try Option 1 first — if it doesn't work, use Option 2.

Option 1 — Node.js (paste in cmd):

npx --yes http-server "%USERPROFILE%\Downloads" -p 8080 --cors

Option 2 — Python (paste in cmd):

python -m http.server 8080 --directory "%USERPROFILE%\Downloads"
  1. Open Windows Search → type cmd → Enter
  2. Paste one of the commands above and press Enter — wait until it says "Available on..."
  3. Open a new tab and go to: http://localhost:8080/miro_flow_generator.html
  4. Use the tool from that tab — this warning will be gone ✓

Keep the cmd window open while using the tool. If neither command works, install Node.js (takes 2 min), then use Option 1.

Miro connection
1. Go to Miro → Settings → Apps → open your Dev App
2. Scroll to Permissions → check boards:read and boards:write
3. Click the blue "Install app and get OAuth token" button
4. Copy the token from the page that appears
